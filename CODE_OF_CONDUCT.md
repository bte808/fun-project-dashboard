# Code of Conduct

The fun project dashboard welcomes practical, respectful discussion focused on public project evidence, maintainable static tooling, and honest verification.

## Expected behavior

- Be considerate of maintainers, contributors, and reporters.
- Critique code, docs, and data-quality decisions without personal attacks.
- Share synthetic examples when real data would expose private people, repositories, machines, or organizations.
- Keep security and privacy reports careful, factual, and coordinated.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory remarks.
- Publishing private data, secrets, tokens, credentials, session data, or non-consensual personal information.
- Misrepresenting the project as affiliated with or endorsed by OpenAI or any other organization.
- Spam, repeated off-topic promotion, or pressure to accept unrelated scope.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; restrict participation; or block users when behavior harms the project or community. Enforcement should be proportionate and focused on restoring a useful maintainer workflow.

## Reporting

Report conduct concerns through the repository maintainer contact path. If the concern includes a security or privacy issue, follow `SECURITY.md` and avoid posting sensitive details in a public issue.
